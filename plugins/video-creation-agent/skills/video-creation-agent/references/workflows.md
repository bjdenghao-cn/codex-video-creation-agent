# 内置创作流程

无需额外技能包。按需求选用一个结构，可混合调整，镜头数量服从时长与动作复杂度。

| 类型 | 适用请求 | 组织方式 |
|---|---|---|
| 叙事短片 | 故事、反转、喜剧 | 建立人物目标 → 阻碍 → 可见行动 → 结果或反转 |
| 动作片段 | 追逐、运动、特效前贴 | 建立空间和方向 → 动作起因 → 连续动作 → 明确结束状态 |
| 产品展示 | 功能介绍、使用情景 | 用户需求 → 操作过程 → 可见效果；不编造性能数据 |
| 知识说明 | 科普、教程 | 一个问题 → 少量清晰步骤 → 示例或结论；事实需可靠依据 |
| 参考改编 | 参考某视频的节奏、镜头 | 实际分析 → 列出保留与替换 → 重写剧情 → 检查连续性 |

例如“牛追着人跑的搞笑视频，8秒”：可暂用两段镜头，先建立追逐误会，再通过牛的真实目标完成笑点。不要强迫使用这个例子中的角色、道具或结尾。

持续检查：角色身份、服饰、道具归属、空间方向、视线、接触点、动作起止与声音是否连贯。时间安排必须能容纳动作和对白；不要把长剧情硬塞进几秒。若用户约束互相冲突，先做可行部分并提出一个明确取舍。
