# 与生成工具衔接

此插件只提供创作与调度规则，不自带生成服务、API 密钥、登录系统或后台任务队列。

检查当前会话是否存在图像/视频生成工具，并阅读该工具的真实说明，核实输入格式、参考素材角色、模型、时长和其他参数。不要根据同名产品或过去任务猜测当前接口。

有工具且获授权：准备匹配的素材与参数 → 提交一次 → 保存返回的任务 ID → 查询同一任务 → 展示真实返回文件或结果链接。遵循工具自己的凭据配置方式，不把凭据复制到提示词、仓库、日志或状态文件。

没有工具：交付完整剧本、首帧提示词、视频提示词、素材用途及待设置参数，供用户在其选择的生成工具执行。明确“尚未生成媒体”。不要提供假接口代码或假成功回执。

任务状态不确定：检查现有 ID、历史返回和工具状态接口。已提交内容发生修改：保留原任务记录，准备新版本并核对新的付费授权，不能把原确认无限延用。

交付后区分容器可播放、参数符合、画面质量可接受及用户验收。发布到网站或社交平台是独立动作，创作授权不自动等于发布授权。
