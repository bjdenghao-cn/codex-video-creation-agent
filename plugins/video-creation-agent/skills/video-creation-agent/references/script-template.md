# 剧本与镜头提示词

按用户需要控制长度。简短请求直接给时间线；复杂作品才展开完整表格，不强制固定两镜头或固定角色。

## 作品
标题与一句话剧情。暂定参数单独列：总时长、比例、视觉风格、声音；未选工具时不猜测分辨率或模型支持。

## 时间线
| 时间 | 画面与动作 | 镜头 | 声音 | 衔接 |
|---|---|---|---|---|
| 起止时间 | 角色做出可见动作及结果 | 景别、角度与必要运动 | 对白、环境、音效 | 接入/接出状态 |

每段保持一个主导动作链。人物、位置、方向、道具和结局写具体；避免只有“震撼、大片感”等空泛评价。用户想要真实提示词时保留真实角色与动作，不用抽象占位符替换已知信息。

## 首帧提示词
主体及位置 + 动作开始前的状态 + 场景空间关系 + 镜头与构图 + 光线/风格 + 必须保留/排除。首帧不要提前表现结尾。

## 视频提示词
起始画面 + 按顺序发生的动作 + 镜头变化 + 声音 + 结束状态。参考素材按工具支持的实际语法绑定。参数与提示词正文分开；不虚构工具选项。

创作完成后核对总时长、因果、用户明确要求与否定约束。只交付用户需要的内容，不附整套模板说明。
