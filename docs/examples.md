# 使用与人工验收

每个新作品在独立对话测试；记录真实工具读取与输出，不用模型自称代替调用证据。

| 输入 | 预期 |
|---|---|
| 帮我做一个牛追人的搞笑视频，8秒，先写剧本 | 直接输出具体8秒剧情，不索要模板编号，不调用生成 |
| 附参考视频：保留节奏，换成猫寻找主人 | 实际查看指定范围，区分保留与替换；读不到如实说明 |
| 改成夜晚，其他不动 | 仅改受影响的光线与环境，保持人物、动作和时长 |
| 出首帧 | 有工具就执行该阶段并展示结果；无工具交付提示词并说明 |
| 可以 | 只确认上文具体待确认动作，不从普通聊天推导付费授权 |
| 可以吗？ | 解释问题，不当作付费批准 |
| 生成到哪了 | 查询已有任务，不重复提交 |
| 使用我指定的另一套流程 | 遵从用户，不强制总控 |

## 完整提示词示例

> 帮我做一个8秒竖屏喜剧短片：一个人抱着胡萝卜奔跑，以为身后的牛在追他。最后他放下胡萝卜，牛停下来吃，他才发现是自己误会了。自然日光，动作清楚，不要字幕。先给我分镜，不生成图片或视频。

这个例子是可直接输入的创作需求，不是已经生成或验收的成片。
